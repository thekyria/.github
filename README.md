# .github

Default community health files for [@thekyria](https://github.com/thekyria)'s public repositories.

GitHub uses the files here for any of my repositories that don't have their own copy.

## What's here

| File | Purpose |
| --- | --- |
| [`FUNDING.yml`](FUNDING.yml) | Sponsor button links |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report issues and open pull requests |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |

## Not inherited

Some files only apply to the repository they're in, so each project keeps its own:

- `LICENSE`
- `.gitignore`
- `.editorconfig`, `.gitattributes`
