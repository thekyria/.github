# Contributing

Thanks for your interest! These are personal projects, so things move at a relaxed pace.

## Issues

- Search existing issues before opening a new one.
- For bugs, include what you expected, what happened, and steps to reproduce.
- For ideas, a short description of the use case helps more than a solution.

## Pull requests

- For anything beyond a small fix, please open an issue first so we can agree on the approach.
- Keep changes focused: one topic per PR.
- Follow the existing code style; most repos include an `.editorconfig`.
- Make sure the project builds and any existing tests pass.

## Licensing
