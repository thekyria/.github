# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report it privately through GitHub:
go to the repository's **Security** tab and click **Report a vulnerability**.

Please include:
- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- affected versions or commits, if known.

I'll try to acknowledge reports within a week. These are personal projects maintained in my spare time, so fixes are best-effort.

## Supported versions

Only the latest version on the default branch is supported.
